# Prop Rule Watch

A dated record of rule changes at futures prop firms, so traders can see what changed after the day they bought their account.

- `index.html` is the site.
- `data/changes.json` holds the dated rule changes.
- `data/presets.json` holds the consistency rules used by the payout check.

Entries come from public sources and each one links to its source. This site is not affiliated with any prop firm. Confirm any rule with your firm before trading on it.
